# YouGlass 1.0.9

This release packages the current YouGlass native experience with a refreshed Apple Icon Composer app icon and stronger account-aware YouTube data handling.

## Highlights

- Added the new YouGlass purple-and-pink Liquid Glass app icon as an Apple Icon Composer document, with generated macOS icon resources included in release builds.
- Improved signed-in feed, subscription, history, channel, comments, live-chat, and playback data paths so the native interface can reflect the connected YouTube account when the API and account session allow it.
- Kept video playback, captions, desktop Picture in Picture, and live playback controls inside the YouGlass experience instead of routing normal viewing to a separate browser window.
- Added the native debug engine, structured diagnostics, request support bundle export, and troubleshooting controls exposed through Settings.
- Refined the color-coded settings window, account refresh actions, recommendation state, and player startup/teardown handling.
- Updated the release workflow for the current macOS/Xcode toolchain so the Icon Composer asset is compiled during signed distribution builds.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- Existing Google sign-in, YouTube API credentials, playback checkpoints, comments, live chat, Picture in Picture, settings, and Sparkle preferences are preserved.
- No new account or YouTube API permissions are required.

## Update path

Stable updates are delivered through the signed Sparkle feed hosted on GitHub Releases. YouGlass checks the appcast at the configured GitHub release URL.
