# YouGlass 1.13.5

This patch release is a broad stability and polish pass for the native YouGlass experience. It keeps the recent player improvements while making navigation, Home, and account-backed loading more reliable during everyday use.

## What’s improved

- Home now presents a compact, readable connection state for offline, local, syncing, connected, and setup-required modes.
- `For You` remains the first Home section, with Continue Watching shown only when real playback checkpoints exist.
- Fast navigation and search now cancel stale work so an older response cannot replace the page you just selected.
- Channel, playlist, account refresh, and card-resolution loading now use the same stale-request protection.
- Repeated thumbnail and avatar requests are coalesced, and the subscription sidebar now stays responsive with large accounts.
- Home and player ambience keeps the themed palette without continuously repainting the full window while idle. Reduce Motion is honored for hover and parallax effects.
- Native player captions, hover controls, playback state, speed labels, and the themed player surfaces from 1.13.4 remain included.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- Existing Google sign-in, YouTube API credentials, subscriptions, history, likes, comments, live chat, Picture in Picture, Settings, and Sparkle preferences are preserved.
- No new account or YouTube API permissions are required.

## Update path

Stable updates are delivered through the signed Sparkle feed hosted on GitHub Releases. YouGlass checks the appcast at the configured GitHub release URL.
