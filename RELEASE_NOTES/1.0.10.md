# YouGlass 1.0.10

This is a stability release focused on native macOS lifecycle safety, account accuracy, and dependable feed refreshes.

## Highlights

- Serialized hidden WebKit feed bridges and added navigation-generation guards so late callbacks cannot mutate a newer request or tear down the wrong remote layer tree.
- Avoided the hidden homepage WebKit bridge when an OAuth session is available, reducing offscreen WebKit activity during normal signed-in use.
- Made OAuth the authoritative source for subscriptions, comments, ratings, likes, and live-chat metadata when available. Watch history continues to use the signed-in YouTube session because the YouTube Data API does not expose a private watch-history endpoint.
- Added request spacing, 429 cooldown handling, response-cache lifetimes, and duplicate refresh suppression to keep recommendations current without issuing overlapping or stale requests.
- Added a repeatable redacted debug export containing YouGlass diagnostics, matching native crash reports, and best-effort unified logs for future crash reproduction.
- Preserved the native player, comments, live chat, Picture in Picture, settings, and Sparkle update paths.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- Existing Google sign-in, YouTube API credentials, playback checkpoints, comments, live chat, Picture in Picture, settings, and Sparkle preferences are preserved.
- No new account or YouTube API permissions are required.

## Update path

Stable updates are delivered through the signed Sparkle feed hosted on GitHub Releases. YouGlass checks the appcast at the configured GitHub release URL.
