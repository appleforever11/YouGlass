# YouGlass 2.3.1

This corrective release prevents a crash after closing and reopening the native YouTube browser window on macOS 27.

- Programmatically created browser windows are now explicitly retained with `isReleasedWhenClosed = false`, as required for Swift and ARC clients.
- WebKit finish callbacks from a replaced browser surface are ignored safely.
- The browser title remains stable without mutating window chrome from the navigation-finish callback.

The 2.3.0 recommendation, Library, playback, theme, and screenshot-tour improvements are included unchanged. Existing accounts, preferences, Library data, and playback checkpoints are preserved.

Requires macOS 14 or later on Apple Silicon. Install from the DMG or ZIP, or choose **YouGlass > Check for Updates…**.
