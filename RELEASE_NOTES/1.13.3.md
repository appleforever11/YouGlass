# YouGlass 1.13.3

This patch release completes the Theme Center update and fixes the Settings layout and scrolling behavior on current macOS versions.

## Highlights

- Adds Theme Center with 12 coordinated environments, each with paired light and dark previews.
- Unifies the glass color system across Home, channels, the player, compact windows, and Settings.
- Keeps background glow, glass tint, light/dark mode, and reduced ambient motion controls available from Appearance.

## Settings fixes

- Appearance now opens at the true top of the page instead of below the header or inside an oversized blank document.
- Appearance scrolls through the complete theme catalog and reaches the final theme cards without an empty lower region.
- General and the other Settings pages keep their headers, spacing, and controls aligned to the top of the detail area without clipping.
- Switching Settings pages resets the new page to its visual top while leaving user-driven scrolling intact afterwards.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- Existing Google sign-in, YouTube API credentials, subscriptions, history, likes, comments, live chat, Picture in Picture, Settings, and Sparkle preferences are preserved.
- No new account or YouTube API permissions are required.

## Update path

Stable updates are delivered through the signed Sparkle feed hosted on GitHub Releases. YouGlass checks the appcast at the configured GitHub release URL.
