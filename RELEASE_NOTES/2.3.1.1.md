# YouGlass 2.3.1(a)

This follow-up 2.3.1 build makes everyday playback and browsing lighter while tightening the native Picture in Picture handoff.

## Playback and Picture in Picture

- Expanded playback, the compact player, and desktop Picture in Picture now reuse one playback owner and WebKit surface, preserving the current timestamp and transport state during handoff.
- Stale play requests, retired WebKit callbacks, duplicate transport messages, and redundant DOM/caption refreshes are ignored or coalesced so transitions do less work.
- Compact and Picture in Picture surfaces skip hidden comments/details work, and stopped or replaced playback releases its page cleanly.

## Home and memory use

- Default Home suggestions now favor subscribed channels and recent viewing, likes, and saves, while preserving source order inside relevance groups and placing unrelated discovery later.
- Image decoding and cache limits are bounded for cards, avatars, and hero artwork. Account browser pages are released when their window closes without removing session data.

Existing accounts, preferences, Library data, and playback checkpoints are preserved. Requires macOS 14 or later on Apple Silicon.

This is the `2.3.1(a)` follow-up build. Sparkle uses numeric build `203101` so installations already on `2.3.1` build `203100` can receive it safely. Install from the DMG or ZIP, or choose **YouGlass > Check for Updates…**.
