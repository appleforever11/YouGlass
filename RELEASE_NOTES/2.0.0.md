# YouGlass 2.0.0

YouGlass 2.0 is the biggest YouGlass release yet: a refreshed Glass Prism identity, a much larger Theme Center, and a more dependable local-first YouTube workspace.

## Highlights

- Added the new YouGlass Glass Prism app icon across the Icon Composer source, packaged fallback, and preview artwork.
- Expanded Theme Center from 12 to 24 coordinated Light/Dark environment families, including Aurora Bloom, Midnight Velvet, Ocean Drive, Desert Rose, Alpine Sage, Copper Noir, Lavender Haze, Ruby Signal, Monochrome Studio, Cosmic Coral, Indigo Harbor, and Paper Lantern.
- Added theme collections, environment search, NEW/FEATURED badges, result counts, an empty state, and Surprise me so the larger catalog stays easy to browse.
- Preserved existing theme selections and palette behavior while layering the validated six-digit accent editor on top of each environment.
- Consolidated the local-first experience: For You leads Home, Continue Watching reflects real unfinished playback, Library/collections/notes and queue state stay local, and command palette navigation is available from the keyboard and app chrome.
- Improved player reliability and polish with native captions, readable playback speed choices, transient controls, stable themed ambience, comments in a bounded scroll surface, reachable outer-page scrolling, PIP, Now Playing, and media-key support.
- Kept YouTube Shorts out of recommendations, search/open flows, navigation, and local recommendation/history persistence.
- Retained offline/cache recovery, cancellation guards, bounded thumbnail caching, Reduce Motion support, and macOS 26 crash-avoidance boundaries.

## Upgrade notes

No action is required. Existing account credentials remain in the macOS Keychain, existing local playback/library data stays in place, and the current visual environment continues to be selected after upgrading. The 2.0 theme catalog adds new choices without changing the original environment identities.
