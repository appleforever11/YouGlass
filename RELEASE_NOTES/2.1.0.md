# YouGlass 2.1.0

YouGlass 2.1 makes everyday browsing, your Library, and theme customization clearer and more consistent.

## Highlights

- Refined Home navigation, video cards, section headings, and pointer feedback; the subscription footer stays reachable.
- Added Explore topics that search when you choose one, plus clearer dedicated browsing destinations and channel video grids.
- Improved local Library tabs, search guidance, empty states, and collection creation. Fixed empty pages appearing halfway down the window.
- Split Appearance into Environments and Customize, with readable groups and a theme catalog that scrolls through the complete final row.
- Improved native Settings selection reliability on newer macOS versions.
- Refined the player’s system glass controls, queue feedback, caption presentation, and playback speed labels. Command-Option-M returns either compact or floating playback to the main player.
- Fixed video search responses containing non-video resources and improved recommendation refresh responsiveness while retaining quota safeguards.
- Kept the WebKit surface renderable behind its loading thumbnail during player transitions.

## Upgrade notes

Requires an Apple Silicon Mac with macOS 14 or later. Use **YouGlass > Check for Updates…** to install through Sparkle. Existing Keychain credentials, account sessions, preferences, Library data, and playback history remain in place. Shorts exclusion, bounded caches, and cancellation safeguards remain enabled.
