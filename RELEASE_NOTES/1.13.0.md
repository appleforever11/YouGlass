# YouGlass 1.13.0

This release makes account-aware feeds feel more current, starts videos more quickly, and expands native channel browsing without changing the stable Picture in Picture implementation.

## Highlights

- Refreshes Home recommendations more frequently while preventing duplicate, stale, or overlapping requests.
- Improves signed-in subscription accuracy and shows local YouGlass watch history immediately while account history continues loading.
- Prewarms selected YouTube watch pages over the network so the native player can begin connecting sooner, without adding a hidden WebKit feed bridge.
- Detects playback stalls sooner and records clearer diagnostics when a video cannot start.
- Expands native channel pages with Videos, Shorts, Live, Playlists, and Posts tabs, including public playlist loading and responsive layouts.
- Adds familiar playback shortcuts for play/pause, seeking, mute, and captions.
- Replaces sample recommendations with explicit loading and retry states when account-backed content is not yet available.

## Stability

- Keeps the macOS 26+ WebKit safety path introduced in earlier releases.
- Preserves the existing Picture in Picture window and controls from the 1.12.0 restore point.
- Avoids introducing new Google account scopes, hidden playback windows, or external browser navigation.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- Existing Google sign-in, YouTube API credentials, subscriptions, history, likes, comments, live chat, Picture in Picture, settings, and Sparkle preferences are preserved.
- No new account or YouTube API permissions are required.

## Update path

Stable updates are delivered through the signed Sparkle feed hosted on GitHub Releases. YouGlass checks the appcast at the configured GitHub release URL.
