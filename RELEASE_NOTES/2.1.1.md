# YouGlass 2.1.1

YouGlass 2.1 makes everyday browsing, your Library, and theme customization clearer and more consistent.

## Highlights

- Refined Home navigation, video cards, section headings, and pointer feedback; the subscription footer stays reachable.
- Added Explore topics that search when you choose one, plus clearer dedicated browsing destinations and channel video grids.
- Improved local Library tabs, search guidance, empty states, and collection creation. Fixed empty pages appearing halfway down the window.
- Split Appearance into Environments and Customize, with readable groups and a theme catalog that scrolls through the complete final row.
- Improved native Settings selection reliability on newer macOS versions.
- Refined the player’s system glass controls, queue feedback, caption presentation, and playback speed labels. Command-Option-M returns compact or floating playback to the main player.
- Fixed mixed-resource search responses and improved recommendation refresh responsiveness while retaining quota safeguards.
- Kept WebKit renderable behind the loading thumbnail during player transitions.
- Preserved the normal Refresh button across supported macOS versions. Native pull-to-refresh requires a build with the macOS 27 SDK.

## Upgrade notes

Requires an Apple Silicon Mac with macOS 14 or later. Use **YouGlass > Check for Updates…** to install through Sparkle. Existing Keychain credentials, sessions, preferences, Library data, and playback history remain in place. Shorts exclusion, bounded caches, and cancellation safeguards remain enabled.

Version 2.1.1 includes the Xcode 26 compatibility correction caught before 2.1.0 was distributed.
