# YouGlass 1.13.2

This release completes the 1.13 distribution repair while retaining all feed, playback, history, and native channel improvements.

## Distribution fix

- Signs the final DMG container with the YouGlass Developer ID identity and a secure Apple timestamp.
- Requires explicit Apple notarization acceptance before publishing.
- Staples and validates the Apple trust ticket on both the app and final DMG.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- Existing Google sign-in, YouTube API credentials, subscriptions, history, likes, comments, live chat, Picture in Picture, settings, and Sparkle preferences are preserved.
- No new account or YouTube API permissions are required.

## Update path

Stable updates are delivered through the signed Sparkle feed hosted on GitHub Releases. YouGlass checks the appcast at the configured GitHub release URL.
