# YouGlass 1.0.7

This release makes the signed-in Home feed more relevant while preserving the dedicated Shorts experience and existing playback and PIP behavior.

## Highlights

- Removed Shorts and reel cards from the primary Home recommendation rows; Shorts remain available from the Shorts section.
- Blended available signed-in YouTube homepage and account signals with subscribed channels, watched history, liked videos, saved videos, topic seeds, and freshness.
- Added ranking boosts for subscribed, saved, liked, and topic-related videos while reducing recently watched duplicates.
- Added channel diversity guardrails so one channel cannot crowd out the Home feed.
- Improved local cache and fallback behavior so the last useful personalized feed remains visible during rate limits or temporary API failures.
- Added regression coverage for Shorts filtering and account-signal ranking.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- No new account or YouTube API permissions are required.
- Existing Google sign-in, playback checkpoints, PIP, captions, comments, settings, and Sparkle preferences are preserved.
