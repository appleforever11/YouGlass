# YouGlass 1.0.4

This patch hardens video playback and PIP cleanup on Apple Silicon Macs.

## Highlights

- Fixed a crash that could occur when switching videos, dismissing PIP, or closing the player while WebKit was committing a media frame.
- Kept the native player surface lifetime stable during video changes to reduce stale WebKit layer-tree callbacks.
- Ignored late playback, navigation, and snapshot callbacks after a player has been dismissed.
- Made desktop PIP teardown orderly so closed player surfaces do not continue using stale WebKit resources.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- Existing Google/YouTube account data, settings, and Sparkle preferences are preserved.
