# YouGlass 1.0.1

This patch adds a more tactile way to browse video artwork in YouGlass.

## Highlights

- Added a pointer-reactive parallax hover effect to home feed thumbnails, compact recommendations, channel videos, and Up Next items.
- Added a restrained liquid-glass lift with gentle tilt, image drift, and spring-back motion.
- Kept thumbnail motion inside each artwork frame so hovering does not reflow or resize surrounding cards.
- Improved hover hit testing across the full thumbnail surface.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- No account, playback, or YouTube API behavior changed in this patch.
