# YouGlass 2.3.0

## Better suggestions

- Likes, saves, and recent viewing contribute balanced topic and channel signals, helping surface related uploads instead of repeatedly boosting the same saved videos.
- Up Next uses the current video's topic and channel, including when offline. Independent search results remain useful when one request fails.
- Fallback discovery rotates through subscription channels and search interests without increasing the number of requests.
- Fresh recommendation rotation keeps unseen candidates ahead of previously shown videos while balancing channels. YouTube Home's own recommendation order remains intact when available.

## More to explore

- Fixed an expanded-player layout stall on macOS 27 by separating viewport sizing from document measurement.
- Hardened player transitions against stale WebKit callbacks and deferred teardown of replaced surfaces.
- In-window mini-player transitions now retire the old video surface before attaching its replacement.
- Home, History, subscriptions, and other loaded lists retain videos that previously disappeared after the first 28 items.
- Faster duplicate filtering keeps the first occurrence and preserves source order.
- Refactored recommendation policies, feed presentation, Library views, API response models, and theme palettes into focused components with regression coverage.

Requires macOS 14 or later on Apple Silicon. Existing accounts, preferences, Library data, and playback checkpoints are preserved. Install from the DMG or ZIP, or choose **YouGlass > Check for Updates…**.

[See the updated app screenshot tour](https://github.com/appleforever11/YouGlass/blob/v2.3.0/docs/SCREENSHOTS.md).

## Known playback limitation

During macOS 27 beta testing, switching between player surfaces intermittently produced a black video surface or first-frame timeout. The player exposes **Retry playback** for recovery. This release improves layout and handoff behavior but does not eliminate that intermittent issue.
