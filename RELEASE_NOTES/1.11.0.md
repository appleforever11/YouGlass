# YouGlass 1.11.0

This release prioritizes crash resistance and trustworthy account refreshes on current macOS versions before adding more playback surface area.

## Highlights

- Added a macOS 26+ stability mode for thumbnail motion. Cards keep a restrained hover lift without creating the AppKit pointer-tracking bridge implicated by the recent crash report; the full pointer tilt remains available on older macOS versions.
- Forced hidden compatibility WebViews off on macOS 26+ and kept OAuth, the YouTube Data API, local caches, and visible login/player surfaces as the stable data path.
- Disabled CSS backdrop materials in every YouGlass WebView configuration on macOS 26+ to reduce remote layer-tree pressure while preserving ordinary video and page compositing.
- Expanded the redacted diagnostic export to schema 3, including the active hidden-WebKit and thumbnail-motion safety modes for crash triage.
- Refreshes the foreground Home feed and account-signal data every 3 minutes, and refreshes subscriptions every 10 minutes, while retaining request spacing and duplicate-load suppression.
- Added a visible stability-mode row in Settings so future crash exports and support reports can be compared against the runtime configuration.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- Existing Google sign-in, YouTube API credentials, playback checkpoints, comments, live chat, Picture in Picture, settings, and Sparkle preferences are preserved.
- No new account or YouTube API permissions are required.

## Update path

Stable updates are delivered through the signed Sparkle feed hosted on GitHub Releases. YouGlass checks the appcast at the configured GitHub release URL.
