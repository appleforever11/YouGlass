# YouGlass 1.0.5(a)

This follow-up build restores the known-good native player and compact desktop PIP behavior from the pre-resize-controls baseline.

## Highlights

- Restored the stable native playback surface used by the previous working build.
- Restored reliable play, pause, seek, mute, captions, PIP, and close controls in the main player and desktop PIP.
- Preserved personalized feed loading, subscriptions, playback checkpoints, comments, account state, and the existing Sparkle channel.
- Kept the existing Apple Silicon compatibility target and macOS 14 minimum.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- No new Google, YouTube, or account permissions are required.

This is the `1.0.5(a)` follow-up build. Sparkle uses the higher numeric build `100501` so installations already on `1.0.5` can receive it safely.
