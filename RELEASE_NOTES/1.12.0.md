# YouGlass 1.12.0

This release improves the first moments of playback and keeps signed-in Home recommendations closer to the account's current YouTube activity, while carrying forward the MacBook Neo stability fix.

## Highlights

- Fixed the macOS 27 beta input replay path used on MacBook Neo. Pointer events now replay through the owning YouGlass app delegate even when SwiftUI installs a delegate adaptor, and diagnostics record when a deferred event is installed, replayed, or safely dropped.
- Refreshed the signed-in Home feed more efficiently. Subscription uploads use the OAuth channel IDs already returned by YouTube instead of reloading each channel page, and subscription, account-signal, seed-search, and popular-video sources can refresh concurrently.
- Improved recommendation quality with numeric recency parsing, stronger suppression of recently watched exact videos, stable channel identity keys, and score-preserving round-robin channel diversity.
- Reduced the time before the native player attempts its first frame. Playback control commands now retry at shorter intervals, the media element is reused while YouTube hydrates the watch surface, and the bootstrap begins as soon as the native player surface exists.
- Preserved the macOS 26+ WebKit safe path: hidden homepage bridges remain disabled for OAuth sessions, visible playback remains in the native YouGlass player, and no new WebKit bridge or account permission is introduced.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- Existing Google sign-in, YouTube API credentials, subscriptions, history, likes, comments, live chat, Picture in Picture, settings, and Sparkle preferences are preserved.
- No new account or YouTube API permissions are required.

## Update path

Stable updates are delivered through the signed Sparkle feed hosted on GitHub Releases. YouGlass checks the appcast at the configured GitHub release URL.
