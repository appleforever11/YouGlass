# YouGlass 3.0.0

YouGlass 3 brings a redesigned native browsing experience, a more useful personal Library, and closer alignment with YouTube's own recommendations.

## Browsing and recommendations

- Home uses the YouTube website session's recommendation order when it is available. YouGlass continues to exclude Shorts, ads, playlists, and duplicate videos. When the website feed is unavailable, bounded account and local recommendations remain available.
- Up Next now prefers the suggestions shown on the video's YouTube watch page, with API and local recommendations as fallbacks.
- Home, Library, Search, subscriptions, and custom feeds have clearer navigation and destination-specific refresh behavior. The Library includes collections, notes, and Continue Watching.

## Playback and responsiveness

- The expanded player has a rounded watch surface beside the sidebar, a tighter layout, and less work while building its suggestion rail.
- Independent Home and watch-page requests start together so slower account or comment requests do not hold up recommendations.
- Playback, queue, and Picture in Picture continue to share the same media owner, with saved positions and bounded local state.

Existing accounts, preferences, Library data, and playback checkpoints are preserved. Requires macOS 14 or later on Apple Silicon. Install from the DMG or ZIP, or choose **YouGlass > Check for Updates…**.
