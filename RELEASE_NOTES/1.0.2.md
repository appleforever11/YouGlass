# YouGlass 1.0.2

This maintenance patch makes the updater easier to find and use.

## Highlights

- Added **Check for Updates...** to the native YouGlass application menu.
- Placed the command directly below About and above Settings, following standard macOS menu placement.
- Kept Sparkle’s signed GitHub update flow unchanged.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
