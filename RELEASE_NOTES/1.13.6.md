# YouGlass 1.13.6

This patch release fixes a full-player visual layering issue in which the Home feed could show through the themed player surface.

## What’s improved

- Full-player ambience now has its own opaque theme base, keeping Home headings and recommendation cards completely behind the player.
- The existing light/dark theme colors, ambient gradients, rounded media boundary, and player glow remain intact.
- Player content stays visually self-contained while the native header, video, Up Next rail, metadata, and comments continue to use the same themed surface.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- Existing Google sign-in, YouTube API credentials, subscriptions, history, likes, comments, live chat, Picture in Picture, Settings, and Sparkle preferences are preserved.
- No new account or YouTube API permissions are required.

## Update path

Stable updates are delivered through the signed Sparkle feed hosted on GitHub Releases. YouGlass checks the appcast at the configured GitHub release URL.
