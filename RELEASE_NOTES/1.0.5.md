# YouGlass 1.0.5

This patch refines the native player presentation and compact desktop PIP controls.

## Highlights

- Centered closed captions inside the video surface and kept them in a stable lower-safe area above the video title.
- Prevented YouTube's hidden web-player chrome from shifting captions when the pointer leaves the player.
- Replaced the shared PIP control capsule with three separate glossy Liquid Glass buttons for moving, expanding, and closing the player.
- Matched PIP control sizing, contrast, and pointer targets to the native playback controls.
- Preserved the existing playback, account, settings, and Sparkle update data.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- No account or YouTube API permission changes are required.
