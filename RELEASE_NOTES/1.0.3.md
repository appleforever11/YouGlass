# YouGlass 1.0.3

This patch makes opening a video feel more immediate and stable.

## Highlights

- Re-keyed the native player surface for each selected video so the previous video's WebKit frame cannot flash into the new player.
- Ignored late playback callbacks from an earlier video during fast navigation.
- Reserved the final watch layout before the media surface mounts, reducing the visible resize jump on first load.
- Limited the connection fade to the media pixels so the player frame, controls, and surrounding details stay fixed.
- Kept responsive sizing intact across compact MacBook displays, Mac mini setups, and larger screens.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- No account, playback, or YouTube API permissions change is required.
