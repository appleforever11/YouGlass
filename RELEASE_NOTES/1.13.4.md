# YouGlass 1.13.4

This patch release improves the native player experience with reliable captions, steadier video playback, and a clearer playback-speed control.

## Player improvements

- Captions now appear in the native player surface when a supported YouTube caption track is enabled.
- Caption updates no longer make the live video frame flicker back to its thumbnail.
- Playback controls keep their current media frame while YouTube reports caption, buffering, or other partial state updates.
- The playback-speed menu uses readable labels and clearly shows the active speed.
- Player controls and caption presentation remain usable across the expanded player layout and its themed surfaces.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- Existing Google sign-in, YouTube API credentials, subscriptions, history, likes, comments, live chat, Picture in Picture, Settings, and Sparkle preferences are preserved.
- No new account or YouTube API permissions are required.

## Update path

Stable updates are delivered through the signed Sparkle feed hosted on GitHub Releases. YouGlass checks the appcast at the configured GitHub release URL.
