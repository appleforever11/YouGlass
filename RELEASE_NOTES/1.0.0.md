# YouGlass 1.0.0

YouGlass is now ready for its first GitHub release on Apple Silicon Macs.

## Highlights

- Added the native YouGlass desktop shell with dark and light appearance modes.
- Added Google/YouTube account connection and persistent Keychain-backed session storage.
- Added account-aware home, subscriptions, channel, search, Shorts, library, and history navigation.
- Added the native player with captions, scrubbing, playback controls, comments, live chat, likes, saves, and resume position support when the corresponding YouTube data is available.
- Added desktop Picture in Picture with corner pinning and drag repositioning.
- Added responsive window sizing for MacBook Neo-sized displays, M4 Mac mini displays, and larger external screens.
- Added the YouGlass app icon and liquid-glass visual system.
- Added Sparkle update support through signed GitHub release assets.

## Compatibility

- Apple Silicon only for this release.
- macOS 14 or later.
- A YouTube/Google sign-in is required for account-specific data. Some official YouTube API features also require the app's configured Data API access.
