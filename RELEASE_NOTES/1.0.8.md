# YouGlass 1.0.8

This release adds a native settings experience and makes video startup state more reliable across the main player, picture in picture, and signed-in YouTube sessions.

## Highlights

- Replaced the single-page settings form with a native macOS split-view settings window.
- Added color-coded settings sections for general app behavior, appearance, YouTube account and recommendations, playback, comments and live chat, notifications, privacy, advanced options, and about/help.
- Added account and feed refresh actions, recommendation-cache reset, connection status, and clearer YouTube credential controls.
- Added a larger default settings window with stable resizing behavior so controls remain readable on MacBook and desktop displays.
- Improved first-frame detection and buffering state reporting so the player does not claim playback is ready before a video frame is available.
- Hardened audio startup and media teardown handling around video changes, captions, and picture in picture.
- Added an SSH-based development deployment path for testing a build on a second Mac without touching the stable Sparkle installation.

## Compatibility

- Apple Silicon only.
- macOS 14 or later.
- Existing Google sign-in, YouTube API credentials, playback checkpoints, comments, live chat, picture in picture, settings, and Sparkle preferences are preserved.
- No new account or YouTube API permissions are required.

## Update path

Stable updates are delivered through the signed Sparkle feed hosted on GitHub Releases. YouGlass checks the appcast at the configured GitHub release URL.
